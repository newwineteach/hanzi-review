## 維護

入口來源為 index.html。新增章節時，將該章卡片的「準備中」改成實際連結。

第三章維護來源在本機 ../chapter3-review/，更新後執行 build.cjs、bundle.cjs，再將最新「第三章_六書複習.html」複製為 chapter03/index.html。第三章是自包含HTML，包含LaTeX拼音、字型與教材圖片，不依賴外部公式服務。

GitHub Pages 使用 main 分支根目錄，.nojekyll 保留靜態網站原樣。
